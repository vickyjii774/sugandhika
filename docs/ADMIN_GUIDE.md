# Admin Guide — Sugandhika CMS

## Accessing the Admin Panel

1. Navigate to: `https://your-site.com/admin`
2. Login with your admin credentials
3. You are now in the Sugandhika CMS dashboard

---

## Admin Sections

### Dashboard
Overview of content statistics:
- Total products, published products
- Categories count
- Team members
- Gallery albums and images
- FAQ count
- Recent activity

### Website Settings
Manage global site configuration:
- **Company name** and tagline
- **Logo** upload (PNG/SVG, transparent background recommended)
- **Favicon** upload (32×32 or 64×64 PNG/ICO)
- **Phone number** and WhatsApp number (format: 977XXXXXXXXXX for Nepal)
- **Email** address
- **Physical address**
- **Social media links** (Facebook, Instagram, YouTube, Twitter)
- **Footer text** and copyright
- Click **Save Settings** when done

### Homepage Management
Control every section of the homepage:
- **Enable/Disable** sections using toggles
- **Reorder** sections using up/down arrow buttons
- **Edit** section content (heading, subtitle, etc.)
- **Manage Banners** — add, edit, delete, reorder hero banner slides
- **Why Choose Us** — edit feature cards, icons, descriptions

### Products
Manage your product catalog:
1. Click **Add Product** to create a new product
2. Fill in all required fields:
   - Name, SKU, category
   - Regular price and discount price (in NPR)
   - Short description (shown on cards)
   - Full description, ingredients, benefits, directions
   - Upload main product image
   - Upload additional gallery images
   - Set stock quantity and availability
3. Toggle **Featured** to show on homepage
4. Toggle **Published** when ready to show on website
5. Click **Save**

### Categories
Organize products into categories:
1. Click **Add Category**
2. Enter name and description
3. Upload a category cover image
4. Reorder using up/down buttons
5. Toggle published status

### About Us
Edit the About page content:
- **Our Story** — company history
- **Mission** statement
- **Vision** statement
- **Values** — list your core values
- **Quality Commitment** text
- Upload company images for the about page

### Our Team
Manage team member profiles:
1. Click **Add Team Member**
2. Fill in name, designation, department, biography
3. Upload profile photo
4. Add social links (optional)
5. Toggle **Featured** to show on homepage
6. Toggle **Published** to show on team page
7. Reorder using drag handles or up/down buttons

### Gallery
Manage photo albums:
1. **Create Album** — give it a title, description, cover image
2. Click an album to open it
3. **Upload Images** — select multiple images at once
4. Add title/description to each image
5. Toggle **Featured** to show on homepage gallery preview
6. Reorder images within albums

### FAQs
Manage frequently asked questions:
1. **Add FAQ Category** (e.g., "Ordering", "Products", "Delivery")
2. **Add FAQ** — write question and answer
3. Toggle **Featured** to show on homepage
4. Reorder within categories

### Navigation
Control the main menu:
- Edit menu item **labels** and **URLs**
- Toggle **visibility** of menu items
- Reorder items using up/down buttons

### SEO Settings
Manage SEO for each page:
- Page title (shows in browser tab and search results)
- Meta description (shows in search results)
- Open Graph image (shows when shared on social media)
- Keywords

### User Management (Super Admin only)
Manage admin user accounts:
- **SUPER_ADMIN** — full access including user management and settings
- **CONTENT_ADMIN** — can manage all content but not users/settings
- **EDITOR** — can edit assigned content

## WhatsApp Number Setup

The WhatsApp number is used for all order buttons across the site.

Format: **Nepal international format without + sign**
- Example: `9779801234567` (977 = Nepal country code)

Update in: **Settings → WhatsApp Number**

## Image Guidelines

| Use | Recommended Size | Format |
|-----|-----------------|--------|
| Logo | 300×80px | PNG (transparent) |
| Favicon | 64×64px | PNG or ICO |
| Product Main | 800×800px | JPG/PNG |
| Product Gallery | 800×600px | JPG/PNG |
| Category Cover | 600×400px | JPG/PNG |
| Team Photo | 400×400px | JPG/PNG |
| Gallery Image | 1200×800px | JPG/PNG |
| Hero Banner | 1600×800px | JPG/PNG |

**Max file size:** 10MB per image

## Publishing Workflow

Content states:
- **Draft/Unpublished** — saved but not visible on the public website
- **Published** — visible to all website visitors

Always use **Preview** before publishing important content changes.
